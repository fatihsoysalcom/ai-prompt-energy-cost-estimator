# AI Prompt Energy Cost Estimator

This example Python script demonstrates the core concept of 'EcoPrompt' by modeling the hidden physical cost of AI prompts. It estimates energy consumption and CO2 emissions based on the prompt's length (as a proxy for computational load) and hypothetical energy-to-CO2 conversion factors. The script illustrates how one might begin to quantify the environmental impact of AI interactions without direct telemetry.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
